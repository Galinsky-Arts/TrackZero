# Groove creator settings

Creator settings preview applies actual DRE cadence and positive-tail rarity rules, verifies current recording authority and rejects mixed paid/point/Groove identities. It presents stock, completion gates and relative weights with a clear shared-transition/headphone/speaker disclosure; rare grants are not guaranteed.

Private preview/publication handlers require approved authenticated endpoint codecs. Publication requires explicit proof and a stable operation ID. The actual DRE transaction bridge atomically commits channel reservations, stock, catalog and versioned station policy, rechecking current authority and optimistic version at the endpoint. No individual client-side reservation writes stand in for a committed publication.

Tests compose the actual DRE registry/rules and test invalid cadence/gates, cross-role/channel denial, unauthorized proofs and retry. The host still must provision authenticated endpoint identity/keys and recording upload/rights verification; this slice receives approved recording IDs rather than uploading plaintext or inventing key distribution. The accessible table is a preview component; production app mounting remains integration work.
