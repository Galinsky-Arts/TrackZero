# TZ-03 station identity and storefront shell

The draft branch validates public station metadata and renders an accessible, inert catalog. Text is escaped; artwork is limited to configured HTTPS origins; there are no purchase, entitlement or playback controls. A scoped SQLite catalog persists public metadata and a framework-neutral handler plus bounded Node HTTP endpoint serve public pages and authenticated publishing. The Node boundary uses an operator configured HTTPS public origin rather than client Host or forwarded headers.

An artist or label role must come from a matching durable TZ-02 account lookup through `createCatalogPublisherAuthenticator`; provider role claims are ignored. A station ID must also have an operator-provisioned, immutable claim binding its tenant, application and owner subject. The public handler cannot create or transfer claims. Publishing checks the claim before invoking an independently supplied complete-product rights verifier and rechecks it inside the write transaction. Existing stations without a claim require operator verification and claim provisioning before further edits. These controls prevent first-publisher slug capture and cross-owner updates; they do not attest legal rights themselves.
